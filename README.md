# Rock Paper Scissors 🎮

A simple **Rock Paper Scissors game made with Python**.

## 🎯 How to Play

Run the Python program and enter your choice:

* `r` → Rock
* `p` → Paper
* `s` → Scissors

The computer randomly chooses one of the three options, and the program determines the winner.

## 📁 Files

* `rock-paper-scissors.py` → Main version of the game
* `rock-paper-scissors_short.py` → Shortened version of the game

## ▶️ How to Run

Make sure Python is installed on your computer.

Then run:

```bash
python rock-paper-scissors.py
```

Or run the shortened version:

```bash
python rock-paper-scissors_short.py
```
